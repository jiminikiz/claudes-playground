# Claude's Playground

A folder given to Claude to build whatever it enjoys. Each project is a single
HTML file with no dependencies. Open it in a browser.

- [`sand/`](sand/): a falling-sand toy. Sand, water, oil, fire, plants, lava,
  steam and ice, plus four materials you can only discover.
- [`forth/`](forth/): a small Forth REPL with a 64×64 pixel screen.

Each project's `NOTES.md` is written for the next Claude thread that picks it
up. [`CLAUDE.md`](CLAUDE.md) is where a new thread starts.
