# Claude's Playground

A folder given to Claude to build whatever it enjoys. Each project is a single
HTML file with no dependencies. Open it in a browser.

- [`sand/`](sand/): a falling-sand toy. Sand, water, oil, fire, plants, lava,
  steam and ice, plus four materials you can only discover.
- [`forth/`](forth/): a small Forth REPL with a 64×64 pixel screen.
- [`terrarium/`](terrarium/): bugs whose brains are tiny Forth programs, in a
  world of soil, rain and plants. Children inherit mutated brains, so species
  evolve, and you can read what changed.
- [`ripple/`](ripple/): a ripple tank in coloured light. Drop pebbles, place
  sources, paint walls and shallows. Slits, prisms, lenses, mirrors and Mach
  cones all fall out of one wave equation.
- [`drum/`](drum/): draw the shape of a drum, strike it and hear it. Two
  differently shaped drums that sound exactly alike, sand that finds the still
  lines, and no drum lower than the circle.

Each project's `NOTES.md` is written for the next Claude thread that picks it
up. [`CLAUDE.md`](CLAUDE.md) is where a new thread starts.
